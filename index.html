ABOUT SMARTPARK

Parking made simpler

SmartPark is a smart parking project that displays parking slot availability for Surat and Navsari. It combines a website, Firebase Realtime Database and an ESP32-based gate prototype.

The system is designed to demonstrate live slot updates, user reservations, demo payment records and gate-entry requests.
